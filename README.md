# Roya Khalili Amirabadi — Academic Website

A responsive one-page academic website prepared for GitHub Pages.

## Files
- `index.html` — main academic homepage
- `styles.css` — layout and responsive design
- `script.js` — navigation, filters, and reveal effects
- `assets/roya-khalili-amirabadi.webp` — profile image
- `assets/Roya_Khalili_Amirabadi_CV.pdf` — downloadable CV
- `.nojekyll` — keeps GitHub Pages from applying Jekyll processing

## Publish with GitHub Pages
For the cleanest address, create a GitHub repository named exactly:

`YOUR-GITHUB-USERNAME.github.io`

Upload all files in this folder to the root of that repository, then enable GitHub Pages from the `main` branch and `/ (root)`.
